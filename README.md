# UGC Reels

Claude skills for producing short-form vertical UGC videos.

- `ugc-captain-reels/` assembles finished 9:16 TikTok and Reels videos (30–60s) from raw footage using ffmpeg, styled after reference creators. Nate Flake is the default reference. See `ugc-captain-reels/SKILL.md`.

Requirements: ffmpeg, Python 3, and `pip install faster-whisper` for transcription. A CapCut SRT export works as a fallback.
